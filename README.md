# PARKOUR RUNNER — 2D паркур

Лёгкая игра-паркур для слабых ПК (проверено под AMD E-450, 2 ГБ ОЗУ, Windows 10 64-bit).
Персонаж — парень с фотографии, которую ты прислал. Спрайт вырезан из фото и встроен в игру.

## Что внутри

- **Главное меню** с портретом героя, счётчиком монет и 6 разделами.
- **60 уровней** с нарастающей сложностью: пропасти, шипы, движущиеся и разрушающиеся платформы, монеты, флаг финиша.
- **Бесконечный режим** — беги сколько хватит, рекорд сохраняется.
- **Режим «На время»** — проходи скоростной уровень и бей рекорд.
- **24 скина** — покупаются за монеты, меняют эффект вокруг героя (корона, рога, плащ, антенна и т.д.).
- **Двойной прыжок**, пауза, перезапуск, сохранение прогресса в `%APPDATA%\ParkourGame\save.json`.
- Процедурная генерация и простые фигуры + встроенные звуки — игра почти не нагружает процессор и память.

## Управление

| Клавиша | Действие |
| --- | --- |
| ← → / A D | Движение |
| Space / ↑ / W | Прыжок, второй раз — двойной прыжок |
| P | Пауза |
| Esc | Пауза / назад |
| R | Перезапуск уровня |
| Мышь | Нажатие кнопок меню |

## Сборка EXE через GitHub Actions

1. Залей папку в репозиторий на GitHub (`main.py`, `game.py`, `core.py`, `levels.py`,
   `hero_asset.py`, `requirements.txt`, `.github/workflows/build.yml`).
2. workflow **Build Windows EXE** запустится сам при пуше в `main`.
3. Готовый `ParkourRunner.exe` скачать можно во вкладке **Actions → Build Windows EXE → Artifacts**.
4. Чтобы получить ссылку в **Releases**, создай тег `v1.0` и запушь его:
   ```
   git tag v1.0
   git push origin v1.0
   ```

## Локальный запуск (для разработки)

```
pip install -r requirements.txt
python main.py
```

## Размер и требования

- Размер окна: 800×600, 60 FPS.
- ОЗУ: ~80–150 МБ.
- Windows 7/8/10/11 (x64).
- Для очень слабого ПК можно снизить FPS до 45 в `core.py` (`FPS = 45`).
